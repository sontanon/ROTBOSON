# rbs-viz

**Role.** A placeholder for a visualization pipeline over `rbs-io` output, for example field movies along a continuation campaign. It has no code yet.

Plots today come from Python:
- `tools/plot_star.py` draws the fields of one solution and compares two;
- `tools/plot_fold_curve.py` draws ω against ψ₀ and the mass against ω for a campaign.

**Tests.** None.
