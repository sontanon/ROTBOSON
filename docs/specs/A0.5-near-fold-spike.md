# A0.5 · Near-fold solver spike

**Question:** does the BlockFieldKrylov linear solver keep working as the solution approaches the ω turning point ("the fold")? Every measurement so far was made a few Newton steps from the starting guess, never near a fold. Reaching folds is the whole job, so this decides whether we build on this backend.

**Exit check:**
1. A results table (`docs/results/A0.5-near-fold.md`) of Krylov iterations, true residual, and error against the distance to the fold, at N=128 and N=256, for three preconditioners.
2. One full Newton solve converging at the state closest to the fold.
3. A stale-preconditioner sweep (factor once, solve along the branch).
4. A written explanation of the bordered system, with a numerical check (`docs/notes/bordered-omega-system.md`).
5. The owner's go/no-go verdict.

## Background: the bordered system

The unknowns are the six fields u (6·dim values) plus one frequency unknown ξ (the solver works with ξ, and ω = ω(ξ)). The Newton matrix is

```
J = [ A    b  ]      A = ∂F/∂u   (6·dim × 6·dim, the fixed-ω Jacobian)
    [ cᵀ   c_w ]     b = ∂F/∂ξ   (one column)
                     last row: the constraint row
```

- In **fixed-ω** mode the constraint row is `δξ = 0`: `c = 0, c_w = 1`.
- In **fixed-φ** mode (what campaigns use near the fold) it pins ψ at one grid node k: `c = e_k, c_w = 0`.

**At the fold, A is singular but J is not.** Parametrize the branch by the pinned value ψ₀. At ω_min, dω/dψ₀ = 0 while du/dψ₀ ≠ 0. Differentiating F(u, ξ) = 0 along the branch gives A·(du/dψ₀) = 0, so A has a null vector. J stays nonsingular, because pinning ψ is exactly what makes the fold a regular point of the full system. That is why campaigns switch to fixed-φ near the fold, and why eliminating ξ exactly (which needs A⁻¹) is unstable there.

## The three preconditioners

Let D = blockdiag(J₁₁, …, J₆₆) be the six factored field blocks (what BlockFieldKrylov builds today).

1. **Block Jacobi (existing).** z = D⁻¹v on the fields; identity on the ξ slot. It ignores the b column and the constraint row; FGMRES has to recover them.
2. **Bordered block Jacobi (new).** Block Jacobi, except that the block of the pinned field g (ψ in fixed-φ mode) is factored together with the frequency slot, as one (dim+1) sparse block:
   ```
   B_g = [ A_gg   b_g ]      b_g: the ξ column restricted to field g's rows
         [ c_gᵀ   c_w ]      c_g: the constraint row restricted to field g's columns
   ```
   The other fields use their plain blocks. Same cost as block Jacobi.

   **Why this is needed (found in NR-11).** The scalar-field equation is linear in ψ, so at every solution A_ψψ ψ = F_ψ = 0: **the ψ block is exactly singular at every converged state**, not just at the fold. (Measured: ‖A_ψψ ψ‖ / (‖A_ψψ‖‖ψ‖) between 2e-16 and 3e-13 at all ten test states.) ω is the eigenvalue of that linear problem and ψ its eigenvector. Plain block Jacobi therefore applies a near-singular inverse, and FGMRES fails even far from the fold. The bordered block B_ψ is the standard regularization of a simple eigenvalue problem: it is regular when the pin node has ψ ≠ 0 and the eigenvalue is simple.

   A first version (NR-10) used the Schur form instead: z_w = (v_w − cᵀD⁻¹v)/s with s = c_w − cᵀD⁻¹b. It converged too (26 to 137 iterations), but only through cancellation of two huge terms along ψ, which is Keller's unstable elimination again. NR-11 replaced it with the factored block (21 to 35 iterations).

3. **Block Gauss–Seidel (new).** Use the couplings below the block diagonal: for g = 0..5, z_g = J_gg⁻¹ (v_g − Σ_{h<g} J_gh z_h); identity on the ξ slot. Same factorizations; extra cost is the off-diagonal matrix-vector products. It inverts the same singular ψ block as block Jacobi, so it fails the same way on converged states.

## Test data

The C campaign `out/campaigns/runbook-l1` (on this machine only; `out/` is not in git) walked the l=1 branch to the fold:

- 165 converged N=128 states (dr=0.125), ψ₀ from 0.003 to 0.362;
- 4 converged N=256 states (dr=0.0625), ψ₀ from 0.365 to 0.400, on both sides of the fold;
- fold estimate (`summary.json`): ψ₀* ≈ 0.37616, ω* ≈ 0.645530.

Distance to the fold is measured as d = ψ₀* − ψ₀ (positive before the fold, negative after it).

Gotchas: `state.json` stores absolute paths from another machine (`/workspace/rotboson/...`); use only the last path component. Each `solution.h5` stores the solved fields as datasets `log_alpha_f.asc, beta_f.asc, log_h_f.asc, log_a_f.asc, psi_f.asc, lambda_f.asc` (shape NrTotal × NzTotal, row-major, i.e. index i·NzTotal + j), the solved frequency as `w_f.asc`, and the grid in the root attributes (`NrTotal, NzTotal, ghost, dr, dz, l, m, fixedPhiR, fixedPhiZ`).

**Self-check:** every exported state is a converged solution, so the Rust residual at that state must be tiny (below 1e-6 in max norm). If it is not, the export layout or parameters are wrong, and every other number is meaningless.

## The experiments

All run by the harness `ng/spikes/nearfold` (a standalone crate like `ng/spikes/faer-lu`, outside the workspace).

| Experiment | What | Records |
|---|---|---|
| `linear` | For each state and each preconditioner: assemble J at the state (fixed-φ); right-hand side b = J·x_true with x_true = (neighbor state − this state), a direction along the branch; solve with FGMRES to a relative tolerance of 1e-10. At N=128, also solve with faer full LU as a reference. | iterations, true relative residual, relative error against x_true, factor seconds, solve seconds |
| `stale` | Per N: factor the preconditioner at the state farthest from the fold, then solve every other state's system with those stale blocks (`solve_stale`). | iterations against distance |
| `newton` | At the closest-to-fold state of each N: start from the neighbor's fields with ψ at the pin node set to this state's value; run the full Newton solve with BlockFieldKrylov. | converged?, Newton iterations, total Krylov iterations, max field-relative difference from the C state |
| `eig` | N=128 only: estimate the smallest-magnitude eigenvalue of the fixed-ω Jacobian (assembled with `fixed_phi = None`; its singularity is A's) and of the fixed-φ J, by inverse iteration with faer LU, for each state. | λ_min(fixed-ω), λ_min(fixed-φ) against distance |

`eig` is the numerical check for the write-up: λ_min of the fixed-ω matrix should go to zero at the fold, while the fixed-φ one should not.

## Proposed verdict rule (the owner decides)

**GO** if the best preconditioner:
1. reaches the 1e-10 true residual at every state;
2. needs at the closest state at most 3× the iterations it needs at the farthest state;
3. converges the `newton` experiment at both N;
4. keeps `stale` iterations within 2× of fresh over the whole range.

**Otherwise NO-GO.** The fallbacks are combining bordered with Gauss–Seidel, deflating the near-null direction, or refactoring more often. Each would get a follow-up spike.

## Out of scope

Changing the Newton algorithm, l > 1, fp32, parallelism, and production API design. The harness is a spike: clear code, but not a library.
